# 移动端个人学籍档案界面

基于 [wang-tong/edu-profile](https://github.com/wang-tong/edu-profile) 调整的纯前端界面演示，重点适配手机端的首页、教育信息列表和学籍详情，并保留本地资料编辑与链接分享功能。

## 在线访问

**网站地址：[https://takeray1ee.github.io/edu-profile/](https://takeray1ee.github.io/edu-profile/)**

推荐使用手机浏览器访问。桌面浏览器可切换到 375–430px 的移动视口查看。

> 网站由 GitHub Pages 托管。私人仓库能否继续提供 Pages，取决于账号套餐和 GitHub 的服务规则；仓库设为私人并不等于网站或分享链接具有访问权限保护。

## 页面与功能

| 页面 | 内容 |
| --- | --- |
| 首页 | 顶部导航、推荐卡、调查横幅、功能入口与底部导航 |
| 高等教育信息 | 学籍卡、学历与学位空状态、可展开提示 |
| 高等学籍详情 | 双照片信息卡、学籍资料列表与报告演示入口 |
| 资料编辑 | 基本信息、学校与专业、学籍资料、照片及研究生选填字段 |

- 页面针对 375、390、400、430px 手机宽度进行过布局检查。
- 生成的分享链接使用当前网站地址；分享视图不提供隐藏编辑入口。
- 调查、绑定、照片业务、退出与验证报告等入口采用本地演示提示。
- 官方学历与学位详情尚未核对，不作为已完成的复刻页面。

## 使用方法

1. 打开上方网站地址。
2. 单击首页右上角**退出图标左侧的绿色空白区域**，进入资料编辑表单。
3. 填写资料后，使用“预览效果”查看教育列表和学籍详情。
4. 需要分享时，在编辑页生成并复制分享链接。

隐藏入口是界面交互设计，不是密码验证或权限控制。

## 分享数据说明

本版本不内嵌 GitHub 访问令牌，也不调用参考作者的存储服务。分享数据经过编码后包含在 URL 中，编码不等于加密，持有链接的人可以读取其中的资料。请使用示例数据测试，并在分享前检查填写内容。

本项目是独立界面演示，与官方学信网服务无关联，不能用于学历查询、认证或证明。

## 本地运行

无需安装前端构建依赖。在仓库目录执行：

```sh
python3 -m http.server 8768 --bind 127.0.0.1
```

打开 [http://127.0.0.1:8768/](http://127.0.0.1:8768/)。

如已安装 Node.js，可执行脚本检查：

```sh
node scripts/check-mobile.cjs
```

检查范围包括两个原页面入口和生成分享 HTML 的 JavaScript 语法；虚构资料示例生成到已忽略的 `artifacts/` 目录。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 网站主入口，包含页面、编辑表单与分享页生成模板 |
| `app.html` | 备用页面入口 |

## 部署

当前 GitHub Pages 从 `main` 分支的根目录发布。更新代码并推送后，可在仓库的 **Actions** 中查看构建结果，在 **Settings → Pages** 中检查发布地址和可用状态。
